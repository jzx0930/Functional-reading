# Vue Bits

- 連結：https://vue-bits.dev
- 分類：前端 UI 元件庫 / Vue 動畫
- 一句話用途：以動畫和互動效果為主的 Vue 元件庫，是 React Bits 的官方 Vue 版本，讓 Vue 開發者也有完整的創意動畫元件庫。
- 來源貼文：Threads [@malilion.dev](https://www.threads.com/@malilion.dev/post/DbUQBCSkwMf)（4,059 瀏覽）

## 它是什麼

Vue Bits 是一套專注動畫／互動效果的開源 Vue 元件庫，也是 React Bits 的官方 Vue 版本。那些「看起來很厲害、自己從零刻很花時間」的文字動畫、動態背景、滑鼠特效與互動元件，都能直接取用。

## 收錄內容

- **背景效果**：Aurora、粒子球、光束、波浪、雷達、網格等
- **文字動畫**：Blur Text、Split Text、Shiny Text、Count Up 等
- **互動元件**：Carousel、Dock、Card Nav、Scroll Stack 等
- **技術**：支援 Vue 3、TypeScript、Tailwind CSS
- **安裝**：可透過 jsrepo 或 shadcn CLI，把元件原始碼直接加入專案

## 為什麼方便

Vue 開發者終於有一套完整的創意動畫元件庫。以前看到很酷的 React 動畫元件常要自己改寫成 Vue，現在可以直接找到對應版本，放進 Vue 或 Nuxt 專案。
