# Sticker Forge

- 分類：前端 UI / 貼紙元件 / 小工具
- 一句話用途：互動式貼紙產生器，直接在瀏覽器裡做出有「撕起來／卷曲」感的貼紙，最後複製嵌入碼放到自己的網頁。

> 註：貼文未附官網網址，可用工具名「Sticker Forge」搜尋。本頁附我做的等效互動 demo。

## 它是什麼

Sticker Forge 把原本很靜態的 sticker 變成一個可互動的小元件——在瀏覽器裡即時做出擬真貼紙效果。

## 主要功能

- 調整文字、圖片、顏色與描邊
- 控制貼紙傾斜、背膠、卷曲感（peel/curl）
- 調陰影、光澤，讓畫面更像真實貼紙
- 最後複製嵌入碼，放到自己的網頁

## 適用情境

個人網站彩蛋、產品 landing page 裝飾，或幫 Side Project 加一點記憶點。
