🎬 用 Codex 把網頁轉成影片

AI 影片Codex 工作流

把網頁／WebGPU demo（含互動、動態圖表）直接轉成影片，省掉整個後製流程。

這則在講什麼

有人用 Codex 一天內把 8 個網頁變成影片。約 10 分鐘就能把產品演示（WebGPU code、互動元素、動態圖表）轉成自動化影片——不用卡幀數、不用調色、不用等 render。省掉的不只是軟體費用，而是整個後製流程；省下的時間可以多做幾個 demo。

網頁 / WebGPU demo→ Codex 自動轉檔→ 影片（免後製）

示範專案

Noniv/snowflow_demo：WebGPU + Babylon.js + 手寫 WGSL 的即時程序化雪景（GPU 生成地形、雪變形、程序化角色、布料、水花、大氣）。就是被轉成影片的那種高互動網頁。

相關：Codex 影片 skills（留言補充）

Codex 5.6 + 4 個 skill 全流程閉環（腳本 → 動效 → 剪輯 → 渲染）：

  • HyperFrames（內建）：整片規劃、動效、合成、渲染。
  • Remotion（內建）：React 模板用程式碼量產影片，適合數位人＋動效。
  • video-use：真人素材剪輯，自動辨識鏡頭、卡點、後製。
  • Seedance：影片大模型提示詞工具，生成電影級運鏡指令。
  • DEXA VFX LAB（dexa.art/vfx）：214 種動效瀏覽器即時比較調參，可匯出 Remotion TSX/JSON 或 HyperFrames HTML。
