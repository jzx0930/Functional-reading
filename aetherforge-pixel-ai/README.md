# AetherForge AI（Aether Generate）

- 連結：AetherForge AI（Discord 社群報名 Beta）
- 分類：AI 生圖 / 像素藝術 / 遊戲素材
- 一句話用途：專門「無限生成像素藝術」的 AI 工具，連 GPT/Gemini 難做的 32px 像素圖也能生，支援 Image-to-Image。
- 來源貼文：Threads [@aetherforgeai.c0m](https://www.threads.com/@aetherforgeai.c0m/post/DbmpOo5Gi-Y)（1,424 瀏覽）

## 它是什麼

AetherForge AI 的新功能「**Aether Generate**」正在招募 Beta 測試者。主打**無限生成像素藝術**（包括 GPT/Gemini 難處理的 32px 細像素），並支援 **Image-to-Image（圖生圖）**。定位是給想自製獨特美術風格的 Vibe coding 開發者、遊戲開發者。

## 主要特色

- 無限生成像素藝術（含 32px 等細規格）
- 支援圖生圖（Image-to-Image）
- 免費素材已含角色與怪物可先試品質
- 目標是做出跟別人不同的獨特美術風格

## 價格（Beta）

- 月費 US$34.9 → **US$22.9**（Beta 測試者優惠，測試結束後仍以同價續用）
- 參加方式：在其 Discord 社群頻道留言報名

## 注意事項（留言區討論）

- 有人質疑「測試還要收費」「比 PixelLab 貴」「本地模型就能文生圖吃到飽」；作者回應可先用免費素材確認品質，此服務是給想自製素材的人。
- 也有人反映免費生成次數偏少（生一次不滿意就得等約一週）。
- 屬付費 SaaS，實際划不划算建議先用免費額度評估。
