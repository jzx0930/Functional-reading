# MingCute Icons

- 連結：https://github.com/mingcute-design
- 分類：圖示庫 / 設計資源 / 前端
- 一句話用途：極簡且精緻、開箱即用的開源向量圖示系統，SVG／Web Font／React／Vue 都支援，免費且商業友善。
- 來源貼文：Threads [@malilion.dev](https://www.threads.com/@malilion.dev/post/DbzmoIRk3qe)（1,609 瀏覽）

## 它是什麼

MingCute Icons（by mingcute-design）是一套現代化的圖示設計資源，把「到處拼湊風格、甚至自己刻 SVG」變成「引入程式碼或匯入 Figma 就能瞬間提升視覺質感」。

## 主要特色

- **極簡高質感**：線條俐落、細節圓潤、風格高度統一，專為現代 UI/UX 打造。
- **跨框架開箱即用**：提供原始 SVG、Web Font，並原生整合 React 與 Vue；當元件引入即可動態調顏色與尺寸。
- **完全免費、商業友善**：極寬鬆開源協議，個人／企業可免費商用，可自由改線條與節點。
- **圖庫豐富分類完善**：涵蓋基礎操作、社群媒體、電商、開發工具等；有官方檢索網站方便搜尋。
