# Pixel Koi — 像素錦鯉

單一 HTML 檔，雙擊 `index.html` 就能開。不用安裝、不連網、無相依套件、無 WebGL。

## 操作說明

| 操作 | 作用 |
|---|---|
| `空白鍵` | 暫停 |
| `+` / `-` | 像素大小（4–22 px，越小越細緻但越吃效能） |
| `C` | 切換深水／淺水配色 |
| `B` | 開關景深模糊 |
| `R` | 重新放一池魚（花紋、數量、路線全部重抽） |
| `H` | 收合說明 |

滑鼠不動 3.8 秒後說明會自動淡出，適合當動態桌布。**鼠標永遠顯示。**

## 設成 Windows 動態桌布

Windows 不支援 HTML 當桌布，需要免費開源的 **Lively Wallpaper**。

1. 安裝 Lively（Microsoft Store 搜尋 "Lively Wallpaper"，或 <https://livelywallpaper.app/download/>）
2. 開啟 Lively → 左上角 **＋** → **Browse** 選這個資料夾的 `index.html`，或直接把檔案拖進去
3. 縮圖按右鍵 → **Set as wallpaper**

桌布一片空白的話，先裝 **Microsoft Edge WebView2 Runtime**（Win11 通常內建）。

## 原理

不是用字元畫的，是**低解析度格點**——整個畫面切成 `CELL × CELL` 的方格，
每格只存一個顏色，最後用 `imageSmoothingEnabled = false` 放大，所以邊緣是硬的方塊。

### 錦鯉怎麼長出來的

身體是參數曲面。`u` 從吻端 0 到尾鰭末端 1，`v` 是左右 −1…1：

| 函式 | 做什麼 |
|---|---|
| `halfWidth(u)` | 紡錘輪廓，`u≈0.33` 最寬，尾柄收細但不收到 0（收到 0 身體跟尾鰭會斷開） |
| `sway(u,t)` | 行進波。振幅隨 `u²` 往尾端長大、相位沿身體延遲——魚是靠身體波動游的，不是整隻左右平移 |
| `patternAt(u,v)` | 程序化緋斑／墨斑。每隻魚用自己的亂數種子，所以不會有兩隻一樣 |

### 游動怎麼做到「順」的

這是改最久的部分。第一版的魚很僵，問題不在畫得不夠好，在運動模型：

| 做法 | 為什麼 |
|---|---|
| 轉向用**平滑噪聲 + 一階低通** | 兩個慢速正弦疊起來當噪聲產生「目標轉向速度」，再 `turnRate += (target−turnRate)×dt×1.35`。**轉向速度不能瞬間改變**，這是順的關鍵。第一版是「倒數 → 抽角度 → 等速轉完」，起停都硬切 |
| 轉彎時**整條身體彎向內側** | 魚不是貼圖在旋轉，是身體先彎、再被水推著走。`bend` 跟著實際轉向速度走（略延遲），疊進 `sway()` 成 `u^1.45` 的弧 |
| 推力**隨擺尾脈動** | `0.80 + 0.30×|擺尾相位|`，轉彎再減速 35%。真魚是擺一下、滑一段 |
| 全部以**每秒**為單位 | 位移沒乘 `dt` 的話，120Hz 螢幕上魚會游兩倍快 |
| `dt` 夾在 `[0, 0.05]` | 分頁切到背景再切回來，`now−last` 是一大包，不夾會瞬間暴衝 |

速度刻意調得很慢（1.25–2.8 格/秒），因為原作的魚兩秒之間幾乎不位移，只有姿態在變。

### 三個關鍵決定

1. **深度用「調暗顏色」，不是「降低不透明度」。**
   一開始我用 alpha 表現遠近，結果遠處的魚跟黑底混成一團糊，邊緣全糊掉。
   改成 `顏色 × dim`、alpha 維持接近 1，方塊邊緣才脆。

2. **鰭不能套身體的厚度陰影。**
   身體用 `0.52 + 0.48 × 背部朝上程度 × 厚度` 打光；鰭的厚度趨近 0，
   套進去整片尾鰭就變灰。鰭要單獨用 `0.82 + 0.18 × …`。

3. **緋斑在 `v` 方向要夠寬。**
   `v` 已經正規化成「佔半身寬的比例」，所以半徑 0.2 在 `v` 上只有 20% 寬——
   會變成沿著中線的一條橘色細線。要把 `dv` 乘以 0.30 把斑塊撐開。

### 其他

- 遠的先畫、近的後畫（畫家演算法），不用 z-buffer
- 景深模糊只對 `depth > 0.35` 的魚做 3×3 柔化
- 魚之間有分離力，不然游一游會擠成一團
- 掉頭角度與方向都是亂數，每次轉彎都不一樣

## 可以自己調的參數

都在 `<script>` 開頭：

| 變數 | 意義 |
|---|---|
| `CELL` | 像素大小 |
| `k.wid` | 身體寬 / 身長（預設 0.106–0.136，越大越胖） |
| `TAIL0` | 尾鰭從身體的幾成開始（0.745） |
| `sway()` 的 `0.105` | 擺尾幅度 |
| `C_WHITE` / `C_RED` / `C_DARK` | 配色 |
| `GW*GH/1250` | 魚的密度 |
