# AGAVEDEX

- 連結：https://agavedex.club
- 分類：植物 App / 收藏圖鑑 / 社群
- 一句話用途：把龍舌蘭、塊根、多肉植物的「品種身份、照護、成長、社群紀錄」整理成一個有生命的圖鑑。
- 平台：iOS、Android、網頁版（7 種語言）
- 來源：list.txt 直接收錄的網站連結

## 它是什麼

AGAVEDEX（Living Index）讓你把每一株植物，從第一張照片開始，變成「有身份、有時間線、有社群知識」的完整紀錄。主打三個植物世界：Agave（龍舌蘭）、Caudex（塊根）、Succulent（多肉）。

## 主要功能

- **成長時間線**：自動整理每株植物從第一張到今天的變化，方便比較。
- **品種身份**：連結圖鑑、交種（hybrid）結構與社群資料，保留真正的身份，不靠記憶。
- **照護與相片同處**：光照、澆水、介質與照片共用同一條植物紀錄。
- **社群照護比較**：記錄自己的環境（光照 LUX、時長、澆水間隔…），與同品種社群數據並排比較。
- **收藏變作品**：用相簿資料生成 Pixel Art、DEXMON、封面、IG Story 圖片分享。
